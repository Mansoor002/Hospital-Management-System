# Hospital Management System — SQL Portfolio Project

## Project Overview
This project is a MySQL-based Hospital Management System designed to organize hospital data and perform data analysis using SQL queries.

## Database Tables
- **Hospitals:** Hospital names, addresses, and contact details.
- **Doctors:** Doctor information, specialties, and hospital assignments.
- **Patients:** Patient details and contact information.
- **Appointments:** Appointment dates, patients, doctors, and visit reasons.
- **Departments:** Hospital department information.
- **Medications:** Medication details and descriptions.
- **Prescriptions:** Patient prescriptions and related records.
- **Rooms:** Hospital room numbers and capacities.

## Key SQL Skills Demonstrated
- Database creation and table relationships using primary and foreign keys.
- Data retrieval and filtering using `SELECT`, `WHERE`, and `LIKE`.
- Data analysis using aggregate functions such as `COUNT()`.
- Table relationships using `JOIN` operations.
- Grouping and sorting data using `GROUP BY` and `ORDER BY`.
- Subqueries and Common Table Expressions (CTEs).
- Ranking and advanced queries using window functions.
- Analysis of appointments, doctor distribution, prescriptions, and hospital departments.

## Tools Used
- MySQL
- SQL

## Project Objective
To demonstrate practical SQL skills in database management, data analysis, and extracting meaningful insights from hospital-related data.
